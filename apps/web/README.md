# SWEETBOARD WEB

## Requisitos

- Node.js (v22+) y pnpm (v11.20.0+)
- A `.env.local` file in the web application (copy from [`.env.example`](.env.example))

## Running the application

Run from the root `pnpm --filter web dev`
